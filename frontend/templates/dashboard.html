Live protocol check

Check charging permission

This sends Authorize only over a real OCPP connection. No BootNotification is sent. The tag may be known or unknown, so you can verify Accepted, Blocked, and Invalid outcomes.

Shared station ID: this check supersedes an older connection using the same station ID. Its next valid call is rejected and it must reconnect, even after this probe closes. The check does not interrupt the durable charging session. Use distinct station IDs for independent runs.

Current scope: session history is available through the Sessions tab. Browser scenario execution arrives in the next slice.
